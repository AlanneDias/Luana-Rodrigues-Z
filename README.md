# Luana Rodrigues — Clínica Integrada

Site estático responsivo baseado no layout do site Wix Studio da cliente e no manual de identidade visual **LZ(2).pdf**.

## Paleta oficial

- Roxo #715289 e #75588C
- Dourado #C8AA77 e #8E7144
- Branco #FFFFFF e cinza #CCCCCC

O monograma `assets/monograma-luana.png` foi extraído do PDF enviado pela designer; não é um redesenho.

## Prévia

Abra `index.html` no navegador. Para GitHub Pages, publique o conteúdo na branch `main` e ative Pages nas configurações do repositório.

## Conteúdo e imagens

Textos baseados na versão Wix Studio indicada. Algumas fotografias continuam referenciando o servidor público do Wix. Conferir autorização de uso e imagens finais antes do lançamento. A seção de depoimentos usa imagens ilustrativas que não devem ser interpretadas como retratos confirmados de suas autoras.
## Publicação

A página de entrada `index.html` é autossuficiente e contém a folha de estilos, o JavaScript e o monograma incorporado. Para ativar a URL do GitHub Pages, configure **Settings → Pages → Build and deployment → GitHub Actions** e use o workflow `.github/workflows/pages.yml`.
